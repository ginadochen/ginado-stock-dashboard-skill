# 实测踩坑清单（动手前必读）

这些是真实项目里踩过、会造成**静默错误**的坑。每一条都对应一个会悄悄算错、漏报或误报的场景。 abstractions 后的通用规则，不含任何真实账户数据。

## 数据源

1. **连接器显示 connected ≠ 可用**。上游整域 TCP 不可达时，会话启动时工具注册失败，工具索引里根本没有对应前缀，调用报 `internal_error`。取数前必须跑健康自检并读状态文件；不可用时跳过全部该源调用、不重试、不请求重连、不中断任务。恢复后要能自动补取并重算。
2. **公告语义检索不能用来检测新财报**。按自然语言查「某公司某季度业绩」会返回别的公司公告。必须用「按代码的公告清单 + 时间增量」以及「最新报告期 / 实际披露日是否变化」判定。
3. **港股财报日历经常不完整**。预约披露接口对部分标的只返回已过期的中报，下一期为 null。必须保留公告轮询兜底，不能只靠日历预告。
4. **A/H 报告周期不对齐**。A 股到 Q3 时港股可能还停在 H1。「最新一期对比」会拿中报比三季报。必须按自然年季度映射，并在页面标注周期差。
5. **三重币种**。港股公司记账本位币可能是 CNY、股价是 HKD、账户展示又是 CNY；不同数据接口对同一份财报还会返回不同币种口径。跨市场**只比比率与增速，不比绝对金额**。每个数字都要带币种。
6. **双源分歧要并存**。同一标的股息率、亏损股 PE 在两个源差异很大（常见原因是 TTM 口径 vs 单次年度方案，或负 PE 计算差异）。正常盈利股往往一致。冲突时两个值都保留并标 `conflict`，禁止静默取一，也不要假定某个源总是对的。
7. **休市日历取不到干净数据**时，别用「个股停牌清单」冒充。用交易日历接口，或退而求其次用快照的「最新交易日 == 今日」判断开市；A/H 必须分别判断。
8. **代码格式不统一**。同一标的在两个源可能是 `600XXX.SH` 与 `sh600XXX`、四位港股代码与五位港股代码。映射只在配置里维护一份，全项目统一用主代码命名文件。
9. **QPS 限流**。并发请求会直接被拒；全链路串行 + 节流，价格引擎与财报引擎任务时点错开。

## 口径伪装（红线）

10. **估值分位缺失时，禁止用 K 线价格分位冒充 PE/PB 历史分位**。前复权价跨十年被分红和公司成长扭曲，拿它算分位是「看起来更精确、实际更误导」的假数字。缺就标「未覆盖」，替代锚标 `confidence: reference`，通知附「低置信度、需人工确认」。
11. **一致预期不是一手数据**。平台返回的预测值若机构数为 0，必须标「平台测算值，非一手机构一致预期，需核实原文」。没有可靠预期就写「无可靠一致预期」，不要用近四季趋势外推后包装成「预期值」。
12. **别把分析师目标价画成价格轴上的强视觉标记**。低置信度数字 + 强视觉权重 = 用精确感包装不确定性，还会和「可接受价格带」混成「别人算好的买点」。

## 调度

13. **`HOURLY` + 多个 `BYHOUR` 会被接受但语义错**。实测 `nextRunAt` 落到深夜，等于全天轮询。改用**多条单整点规则**（每个整点一条），并逐条换算时区核对下次触发时间。
14. **节假日调度层排除不了**，任务内必须用交易日历立即静默退出：不取数、不写文件、不发消息。
15. **降噪比功能重要**。纯数值判定放本地脚本（可复现、可回测），定时任务只负责触发 + 读结果 + 决定是否推送。加「同一区间只推一次」的去重状态；无买点时给一条日汇总，避免用户以为系统坏了。

## 产物与渲染

16. **预览面板会剥掉外链资源**。`<link rel=stylesheet>` 和 `<script src>` 返回 200 但样式不生效。所有网页必须单文件自包含，由构建脚本内联 CSS/JS。
17. **按「最新目录」选快照会误选**。同一天新建的目录可能只有部分快照（例如只有财报 JSON，没有行情 JSON）。必须按「含 `quotes.json` 的最新目录」选。
18. **脚本不能用 `Path(__file__).parent.parent` 推断实例根目录**。脚本一旦作为模板被复制进 skill 安装目录，产物会写进技能包自己里面。必须显式 `--root`。
19. **静态 HTML 写不了本地文件，也调不了 MCP**。看板上的表单只能生成可复制指令，由 Agent 执行；不要假装能自动保存。表单数据不写 `localStorage`、不拼 URL。
20. **原生提醒设置常是全量覆盖语义**。改一项前必须先读回现有全部字段回填，否则清空其他设置；这类写操作需单独授权。
21. **财报数字是历史值，行情估值是当前值**。页面要分别标 `as_of` 与 `quote_as_of`，不要把盘中价当收盘价。

## 图表

22. **横轴隔期抽稀会让最后一个标签被裁**。每期一个刻度，月份用两位数字全量标注、年份合并为下方分组带，首尾留白 ≥ 28。
23. **归一化折线图会压掉负值**。亏损期净利为负时，归一化把它变成 0，完全看不出亏损规模。柱状图用真实金额 + 0 线，负值向下延伸才有信息量。
24. **柱端数值必须常显**。悬停不能作为唯一取值途径；按金额量级自适应精度，逐个做防重叠避让，文字加描边保证压在网格线上仍可读。

## 流程

25. **新增一只股票不是加一行**。watchlist → peers → 近 8 季财报 → 买入区间 → 个股详情页 → 首页三处入口 → 重建 + state，缺一步就会留下死链或空页。
26. **demo 与 live 必须物理隔离**。两套数据混进同一份持仓配置，总资产和集中度会算错且不易察觉。切换时强制清空演示数据 + 二次确认。
27. **除权除息后必须重算买入区间**，否则价格轴与估值锚全部失效；把这条写成检测闭环，不要停留在纸面规则。
28. **隐私审计要做成机制**。生产实例会持续产出新的私人文件（归档副本、速递、净值快照、日志）。默认拒绝式 `.gitignore` + 预提交扫描 + 独立 clone 复扫，比「清理一次」可靠得多。
