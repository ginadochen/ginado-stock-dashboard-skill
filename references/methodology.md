# 方法论：区间、护栏与结论

本文件只描述**可配置的通用规则**。任何具体金额、比例、股数都由实例 `config/` 决定，不写死在脚本里；示例值必须明显虚构。

## 可接受价格带（当前可接受 + 偏贵程度标注）

不采用「只在历史低分位才提示」——那会让高估值标的长期静默，看板看起来像坏了。改为给出**当前可接受的价格带 + 估值偏贵程度**。

参考算法（实例可覆盖）：

```
valuation_anchor = 选定估值锚（红利股用股息率分位、周期股用 PB 分位、成长股用 PE/PEG）
expensiveness_d  = max(0, (anchor_percentile - 50) / 100) * safety_factor + base_margin
band             = [price * (1 - d - width), price * (1 - d)]
```

再用 52 周高低位置、均线做收窄，但**不得用价格分位冒充估值分位**。

每个区间必须带三件套：

| 项 | 说明 |
|---|---|
| 安全边际 | 相对锚的折让幅度与依据 |
| 触发确认条件 | 收盘价进入区间且次日不快速收回、无放量杀跌、非盘中插针 |
| 失效条件 | 财报逻辑破坏、除权除息、商品价格大变等，触发即重算 |

**到价不等于买点**。规则生成的参考带不是目标价预测。

## 按行业选锚，不用一把尺子

| 类型 | 主锚 | 陷阱 |
|---|---|---|
| 公用事业 / 红利 | 股息率分位 + 10 年 PE 分位 | 「高股息」不等于便宜，盈利下滑时 PE 分位可能仍在高位 |
| 周期资源 | PB / 周期中枢 + 商品价格假设 | **PE 低不等于便宜**，常是盈利高点特征 |
| 消费 / 制造 | PE / PEG + 股息 | 关注库存与渠道 |
| 平台互联网 | 经调整净利 PE + 分部 | 记账本位币与股价币种要分开 |
| 未盈利 / 次新 | **不给区间** | 无正 PE、上市不足一年，算「合理区间」是虚假精确感 → 标 `observe_only`，只做观察 + 事件提醒 + 仓位上限提示 |

## 集中度护栏（加仓 / 摊薄）

摊薄成本改变的是**账面数字**，不是回本概率，也不改善盈利能力，只放大暴露。实现时必须把这一点显示出来：

- 摊薄计算器同时显示：补 N 股 → 成本降至 X、回本需 Y%、**仓位升至 Z%**、新增投入金额。
- 两条硬红线可配置：`add_capital.limit`（资金上限）与 `concentration_limit.max_ratio`（单一标的最大占比）。
- **分母固定**（默认锁定用户入金前的总资产），不因股价下跌、市值缩水自动放开补仓空间，防止「越跌越补」。
- 整手约束（`lot_size`）必须校验。
- **被动越线**：股价上涨导致占比自然超线时，只标红并停止提示补仓，**不提示减仓**。
- 分批档位由规则生成（例如按触发价折让分档），不是价位预测；每档只推一次。

## 财报对比四层

1. 同比
2. 环比 / 单季同比
3. 近 8 季趋势（营收 / 归母净利柱状图，真实金额 + 0 线）
4. 管理层措辞与指引变化（无结构化数据时标「未覆盖」，不编造）

再加一层**预期差**（实际 vs 预测方向）与**股价反应校验**（披露日前后 1/5/20 日涨跌，判断 headline 与股价反应是否错位）。

- 跨市场按自然年季度映射，**不用「最新一期」直接横比**。
- 同业横比**只在同行业内做**。若观察池里没有同行业对子，必须显式补同业标的或如实写「本层不可用」，不能拿不同行业的公司凑数。
- 盈利质量：毛利率 / 净利率 / 费用率、资产负债率、经营现金流 ÷ 净利润、分部结构。

## 结论表述

一句话结论必须标「机器判定，需人工确认」，并附：

- 这期财报对买入区间的影响
- 数据缺口与置信度
- 完整免责声明（见 `disclaimer.md`）

## 禁止事项

- 不编造一致预期、财务数字、目标价或估值分位。
- 不把低置信度数字做成强视觉标记。
- 不用百分比替代绝对值直觉（先给金额，再给百分比）。
- 不给「保证收益」「必涨」「建议买入」类表述。
