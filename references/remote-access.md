# 可选：让看板在手机上也能打开

> 这一步不是必需的。不做，看板照样在本地正常跑；做了，你在外面也能看。
> 本文只讲思路和边界，不提供现成脚本——因为这一步和你自己的域名、账号强绑定，照抄别人的配置大概率会卡在「为什么我没有这个选项」。

## 先想清楚代价

看板是本地单文件，天然私有。一旦挂到公网，就多了三件事要一直操心：门禁是否有效、进程是否活着、域名是否还在。如果你的使用场景只是「在家里的电脑上看」，**不要做这一步**。

值得做的场景：通勤路上想看持仓、想给手机加个书签、放在桌面小组件里。

## 三种形态，先选一种

| 形态 | 数据是否离开本机 | 备案 | 成本 | 适合 |
|---|---|---|---|---|
| 本机文件直接打开 | 否 | 不需要 | 0 | 只在自己电脑上看 |
| 本机服务 + 隧道回源 | **否**，Cloudflare 只做通道 | 不需要 | 0（隧道免费） | 手机随时看，推荐 |
| 上传到静态托管 | **是**，快照会落到第三方 | 视服务商而定 | 0 起 | 愿意公开或已脱敏 |

**推荐第二条**：本机起一个只读静态服务，隧道把公网请求回源到 `127.0.0.1`。数据始终在你自己磁盘上，托管方只转发字节，不存储、不缓存内容。

第三条要特别小心：看板里有总资产、成本价、持仓股数。上传之前要么彻底脱敏（金额改百分比），要么确认托管商的门禁真的挡住了——很多静态托管的「密码保护」是付费功能，免费版根本没有。

## 关键实现要点

**1. 静态服务必须自己写，不要用 `python -m http.server`**

标准库的那个服务没有任何鉴权，一旦隧道指过去就等于全公开。需要的最小能力：只读（非 GET/HEAD 一律 405）、`Cache-Control: no-store`、`X-Robots-Tag: noindex`。

**2. 门禁放在两层，不要只放一层**

- 第一层在边缘：Cloudflare Access（邮箱一次性验证码），免费额度够个人用，能单独撤销某台设备，还有登录日志。
- 第二层在源站：校验请求是否带边缘注入的身份头（如 `Cf-Access-Authenticated-User-Email`）。客户端自己传这个头到公网会被边缘覆盖或剥离，所以伪造不了；但没有这一层，别人只要能直连 `127.0.0.1` 就绕过了 Access。

只有一层也行，但要知道少了哪一层的保护。

**3. 报告目录要单独挂载**

看板在 `dashboard/`，一次性报告在 `reports/`，是两个目录。只挂前者，报告链接必然 404。挂载多目录时务必做前缀边界检查，挡住 `../` 穿越——`%2e%2e` 这种编码形式也要覆盖。

**4. 隧道进程和源站进程都得常驻**

两个进程缺一个就断：缺源站 → 502（网关到了、回源失败）；缺隧道 → 530 或直接连不上。别把它们挂在某个会话或终端窗口上，那个会话一关就断。做成开机自启 + 守护循环（定时体检、缺谁补谁）最省心。

**5. 域名用子域，别动根域**

如果根域已经指向别的站点，用 `stock.example.com` 这样的子域，避免覆盖现有解析。CNAME 指向 `<tunnel-id>.cfargotunnel.com` 即可，Cloudflare 会自动签证书。

## 不要把数据源凭证搬到云端

有一种看起来更聪明的做法：把行情数据源的 OAuth token 存到边缘函数里，让云端直接取数、直接渲染。

不建议。原因不是「做不到」——那些 MCP 端点确实是标准 HTTP + OAuth，技术上能接。问题是：

- 付费数据源的授权通常限定使用主体和方式，把 token 放进第三方边缘函数，等于让它以你的身份对外提供服务；
- 很多 MCP 端点的 URL 里就写着服务对象（`/vserver_<partner>/`），它是给特定合作方客户端开的通道，不是开放 API，自己注册客户端接进去绕的是合作方授权；
- token 被撤销或过期后，整条链路会静默失败，而你在手机上看不出来是数据错了还是没更新。

**只把行情这类公开接口当备选，估值分位、财报、公告这些仍然靠本机会话取数。** 宁可手机上看的是几小时前的快照，也不要为了「实时」把授权边界弄模糊。

## 排查：先看状态码

| 现象 | 含义 | 先查什么 |
|---|---|---|
| 401 / 登录页 | 门禁生效，正常 | — |
| 502 Bad Gateway | 网关到了，源站没响应 | 本机端口是否在监听 |
| 530 / 连不上 | 边缘找不到隧道后端 | 隧道进程是否在跑 |
| 401 之后还是 502 | 两种门禁叠在一起，或源站刚挂 | 关掉一层、看源站日志 |
| 报告页 404，首页正常 | 报告目录没挂载 | 服务的目录映射配置 |
| 登录页要求重复输入验证码 | 会话时长设太短 | Access 应用的 session duration |

本地自查时注意：某些 shell 会把 `--mount /x=路径` 这类以斜杠开头的参数当成路径做转换（MSYS / Git Bash 常见），参数被吃掉后服务起不来。命令行里用等号连接、或用正斜杠路径通常能避开。

## 最后

做之前先问自己：这个页面里有多少数字是「别人看到会不舒服」的。如果有，别急着上公网——先脱敏，或者只在本机看。挂出去容易，收回来难。
